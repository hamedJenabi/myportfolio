# Hamed Jenabi Portfolio

Personal portfolio for repositioning Hamed Jenabi as a Design Systems Expert & Frontend Platform Lead.

The site focuses on:

- Design systems
- Frontend platform architecture
- Headless CMS and DXP work
- Technical leadership
- Applied AI and AI-enabled product workflows

## Tech Stack

- Next.js 16 App Router
- React 19
- TypeScript runtime support
- Global CSS
- Static deployment friendly output

## Local Development

Use Node `24.18.0`, as defined in `.nvmrc` and `.node-version`.

```bash
yarn install
yarn dev
```

Then open `http://localhost:3000`.

## Build

```bash
yarn build
```

## Content Editing

Most portfolio copy lives in `app/content.js`:

- Profile and contact details
- Navigation
- Hero status items
- Selected work
- Expertise areas
- Leadership highlights
- Skill groups

The page structure lives in `app/page.js`, with styling in `app/globals.css`.
